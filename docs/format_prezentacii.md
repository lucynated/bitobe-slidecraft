# Формат описания презентации

Описание — обычный текстовый файл в `decks/`, по нему `scripts/build_custom.py` собирает PPTX на актуальном шаблоне BITOBE (`library/template.pptx`). Пример целиком: `decks/2026-11-03_slidecraft_itogi.md`.

```
python3 scripts/build_custom.py --from decks/<файл>.md -o decks/<файл>.pptx
```

## Обложка

Первые строки файла — обложка:

```
# Название презентации // во вторую строку
подзаголовок: Slidecraft BITOBE · итоги этапа
для: команды BITOBE              ← на обложке «Подготовлено для команды BITOBE»
дата: 3 ноября 2026
обложка: 4                       ← номер фото-обложки, 1–26, см. ниже
контакты: да                     ← «нет» — без финального слайда «Свяжитесь с нами»
заметки: текст для докладчика
```

`//` — перенос строки в названии. По умолчанию обложка 4, контакты есть.

## Слайд

```
## Надзаголовок | Заголовок-вывод слайда
тип: карточки
- Пункт
- Пункт
вывод: …
заметки: …
```

Надзаголовок — маленькая строка над заголовком (раздел, номер схемы), можно без него: `## Заголовок`. Заголовок пишется выводом, а не темой (см. принцип в `.claude/commands/prezentaciya.md`).

Пункт с подзаголовком: `- Заголовок: текст`. С надписью сверху: `- Шаг 1 / Заголовок: текст`.

## Сетка

Слайды верстаются по модульной сетке мастера шаблона (его направляющим):
- **12 колонок** по 59,5 pt с промежутком 17 pt, поля 29,25 и 930,75;
- **5 строк** в зоне контента, квадратные модули 59,5 pt: от 125,4 (под заголовком) до 491,1 (над колонтитулом).

Каждый блок занимает целое число колонок и строк, а содержимое всегда заполняет все 5 строк. Дополнительные блоки (`лид`, `вывод`, `плашка` и др.) берут по 1–2 строки, остальное отдаётся основному содержимому. Поэтому число пунктов подбирается под сетку:

- карточки, цифры, колонки, шаги — **1, 2, 3, 4 или 6** в ряд (12 колонок делятся поровну);
- цепочка — **2–4 или 6** шагов в строку (5 шагов тоже можно, но тогда ширина блоков не совпадёт с колонками), 7–12 шагов — «змейкой» в две строки, лучше 8 или 12;
- список — **до 5 строк**, по строке сетки на пункт;
- чеклист — до 10 пунктов, в две колонки;
- схема — три колонки сетки: A — колонки 1–3, B — 5–8, C — 10–12; колонки 4 и 9 — под стрелки и подписи.

Внутри плашки заголовок прижат к верху, текст — к низу, как в слайдах банка. В плашке высотой в один модуль весь текст идёт сверху одним потоком.

## Типы слайдов

| тип | что получается | пункты |
|---|---|---|
| `карточки` | 1–4 или 6 серых плашек в ряд | `- Заголовок: текст`, можно `- Надпись / Заголовок: текст` |
| `цифры` | плашки с крупной цифрой | `- 12: слайдов в презентации` |
| `колонки` | плашки со списками | `- Заголовок: пункт; пункт; пункт` |
| `список` | до 5 строк «название — описание» с тонкими линейками | `- Название: описание` |
| `чеклист` | пункты в две колонки с медными маркерами | `- текст` |
| `шаги` | 2, 3, 4 или 6 колонок с крупными номерами | `- текст` или `- Заголовок: текст` |
| `цепочка` | схема-процесс: до 6 шагов в строку, 7–12 — «змейкой» в две строки | `- Шаг: текст` |
| `схема` | блоки на сетке 3 колонки × до 3 строк и стрелки | см. ниже |
| `раздел` | слайд-разделитель шаблона | `текст:` — подпись под названием; `//` — перенос |
| `банк` | слайд банка как есть | `номер: 152` |

`акцент: 3` (или `акцент: 2, 5`) — выделить пункт тёмной плашкой (карточки, цифры, колонки, цепочка). В цепочке последний шаг без акцента обводится медной рамкой.

### Схема

```
## Как это работает | Подбор работает по смыслу, потому что у каждого слайда есть карточка
тип: схема
- A1-2 Банк слайдов: `library/bank.pptx` // 181 слайд — источник для сборки
- B1 Каталог: `catalog.json` // карточка на каждый слайд
- B2 Индекс и страница: индекс для агента, каталог для людей
- C1 Правка каталога: `/obnovit` // правит карточки
- !C2 Подбор и сборка: `/podbor` // собирает PPTX
связи: A1->B1 описан; B1->B2 собирается; C1->B1 правит; B2->C2 читает
```

- `A`, `B`, `C` — колонка, цифра — строка (1–3). `A1-2` — блок на строки 1–2.
- `!` перед блоком — тёмный (главный результат), `?` — пунктирный (пока нет, будущее).
- В тексте блока `//` — новая строка, `` `так` `` — синяя строка (файл, команда, код).
- `связи:` через `;`. `->` — сплошная стрелка, `-->` — пунктирная, после — подпись к стрелке.

## Дополнительные блоки (к любому типу, кроме «банк» и «раздел»)

Ставятся сверху вниз в таком порядке:

| ключ | где | как выглядит |
|---|---|---|
| `лид:` | над содержимым | тёмная полоса с главным тезисом курсивом |
| `цитата:` | над содержимым | курсив PT Serif — цитата, запрос клиента |
| `вывод:` | под содержимым | крупный курсив PT Serif — итог слайда |
| `текст:` | под содержимым | небольшой абзац; `Заголовок: текст` — с подзаголовком |
| `примечание:` | под содержимым | светлая полоса с пояснением |
| `пример:` | под содержимым | синяя плашка, `Подпись: текст` |
| `плашка:` | под содержимым | тёмный блок `Заголовок: пункт; пункт; пункт` — решения, итоги |
| `заметки:` | — | заметки докладчика |

## Что проверяет сборка

- Если текст, по оценке, не помещается, сборка пишет `! слайд N … может не поместиться`. Сократите текст или разделите слайд.
- Неизвестный тип, связь или номер слайда банка — ошибка с понятным текстом.
- Заметки докладчика из слайдов банка не переносятся: в них бывают данные других клиентов.
