# Актуальность, цель, задачи проекта
Актуальность
Цель
Построить объективную картину текущего клиентского опыта и сформировать решения для повышения качества сервиса.
По итогам стратегической сессии GreenTech выделила клиентский сервис как отдельную стратегическую инициативу. При этом само направление требует самостоятельной проработки и конкретизации.
Сегодня в компании отсутствует целостное понимание клиентского пути, а также инструменты оценки удовлетворенности клиентов в ключевых точках контакта. Это затрудняет выявление причин потерь качества сервиса и приоритизацию улучшений.
Дополнительно зафиксированы внутренние барьеры, способные напрямую влиять 
на клиентский опыт: рассогласованность коммуникации между подразделениями, не всегда определенные владельцы процессов и ручной режим управления рядом задач. Проект позволит перевести эти ограничения в клиентскую логику 
и сформировать практические решения 
по улучшению сервиса.
