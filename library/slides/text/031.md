# Соответствие SMART
Соответствие критериям SMART достигается, 
если формулировка цели в одно предложение 
содержит ответы на вопросы о специфичности (S), 
измеримости (M) и времени достижения цели (T) 
и при этом: 
СОГЛАСОВАННОСТЬ (A) 
РЕАЛИСТИЧНОСТЬ (R)
Ключевые заинтересованные стороны согласны с необходимостью 
достижения цели  
Возможно своевременное получение 
всех ресурсов необходимых 
для достижения цели
