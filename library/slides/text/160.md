# Связь корпоративных ценностей и мотиваторов для EVP

на уровне руководства
Связь корпоративных ценностей и мотиваторов для EVP
Все руководители в интервью раскрывают три корпоративные ценности, отвечая на вопросы 
про корпоративную культуру 
и про особенности команды подтверждает проявление ценностей 
в практике управленцев
Забота о людях
Эффективность
Безопасность

| ЦЕННОСТЬ | Значимость для сотрудников | Степень проявления у работодателя | Мотиваторы, которые могут быть рекомендованы как акценты для включения в EVP |
| --- | --- | --- | --- |
| Забота о людях |  |  | Современные условия труда на ГОКе Поддержка коллектива Открытость руководства, развитое наставничество Соцгарантии и страховки |
| Эффективность |  |  | Доп. заработок (межвахта, совмещение) Приоритет внутреннего кадрового резерва |
| Безопасность |  |  | Соблюдение норм охраны труда Репутация надежного работодателя Длительность работы в компании, стабильность |

Примечание
Забота о людях не проявляется у сотрудников как ценность. Выявлен разрыв между тем, как транслируется ценность, и как воспринимают 
ее сотрудники. Сотрудники ожидают, что работодатель будет выполнять свои обещания, но сами они не используют эту ценность как основу сотрудничества внутри коллективов.
