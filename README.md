# Slidecraft BITOBE

Сборка презентаций BITOBE из готовых слайдов банка с помощью Claude Code. Вы пишете запрос обычными словами, агент подбирает слайды по смыслу, показывает карту слайдов и после вашего «ок» собирает PPTX.

## Быстрый старт

1. **Откройте репозиторий в Claude Code** — в браузере, в приложении для компьютера или в терминале.
   Команды `/podbor`, `/prezentaciya` и `/obnovit` появляются, только когда сессия открыта в папке `bitobe-slidecraft`. Не держите проект в папках iCloud («Документы», «Рабочий стол»): синхронизация обрывает запись файлов git.
2. Напишите, например:
   ```
   /podbor КП собственнику розничной сети на однодневную стратегическую сессию для новой управленческой команды
   ```
3. Агент покажет сюжет и карту слайдов: какой слайд под какой тезис, почему, что поменять руками. Поправьте или напишите «ок».
4. Готовая презентация появится в папке `decks/`.

Пример карты и собранной презентации: `decks/2026-11-03_demo_evp_hrd.md` и `.pptx`.

## Новая презентация на шаблоне

Когда нужны не только готовые слайды банка, а своя история — отчёт, итоги этапа, КП со схемой работ:

```
/prezentaciya Итоги пилота для партнёров: что сделали, что получилось, что предлагаем дальше, 12 слайдов
```

1. Агент пишет сюжет заголовками-выводами (принцип красной шапочки): одни заголовки подряд читаются как история. Вы правите или пишете «ок».
2. Агент описывает слайды в `decks/<дата>_<тема>.md`: карточки, цифры, списки, схемы-процессы, схемы из блоков, слайды банка по номеру.
3. Скрипт собирает PPTX на актуальном шаблоне BITOBE: фото-обложка (26 вариантов), макеты шаблона с колонтитулом, схемы — фигурами PowerPoint, которые можно править, в конце «Свяжитесь с нами».

Формат описания: `docs/format_prezentacii.md`. Пример: `decks/2026-11-03_slidecraft_itogi.md` — презентация об итогах первого этапа Slidecraft.

## Каталог

Откройте `app/index.html` в браузере. Там превью всех 181 слайда с тезисами, фильтры, дубли и примеры подбора.

Если видите неточную карточку, напишите в Claude Code:
```
/obnovit слайд 125: тезис неточный, на самом деле он про …
```

## Что нужно для работы локально

- Python 3.10+ и `pip install -r requirements.txt`
- LibreOffice и poppler — только для проверки собранной презентации картинками:
  - macOS: `brew install --cask libreoffice && brew install poppler`
  - Windows: установить LibreOffice с сайта, poppler — через `choco install poppler` или `winget`

В Claude Code в браузере зависимости агент поставит сам.

## Структура

| Путь | Что это |
|---|---|
| `library/bank.pptx` | Банк слайдов, источник для сборки |
| `library/template.pptx` | Актуальный шаблон BITOBE: макеты, обложки, контакты |
| `library/catalog.json` | Каталог: карточка на каждый слайд + дубли |
| `library/slides/` | Превью и тексты слайдов |
| `app/index.html` | Страница каталога |
| `decks/` | Карты слайдов и собранные презентации |
| `scripts/` | Сборка, проверка, пересборка страницы |
| `.claude/commands/` | Команды `/podbor`, `/obnovit` и `/prezentaciya` |
| `taxonomy.md` | Схема карточки |
| `docs/` | Следующий этап: архив КП из CRM |

## Правила работы с банком

- Свои правки карточек делайте через `/obnovit`. Перед коммитом каталог проверяется автоматически.
- Изменения в общий банк — через pull request, их смотрит владелец банка.
- Клиентские презентации из `decks/` в репозиторий не коммитятся: по умолчанию git их игнорирует.
